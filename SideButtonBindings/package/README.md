# SideButtonBindings

<details>
<summary>中文读我</summary>

在游戏的“设置 → 按键设置”中，使用鼠标侧键设置快捷键。

- 支持鼠标前进、后退侧键及其他附加鼠标按键（第 4–7 键）。
- 支持侧键与 Ctrl、Alt、Shift 的组合。
- 支持游戏原生功能，以及 CE 等 Mod 添加到同一设置界面的可改键功能。

</details>

<details>
<summary>README</summary>

Use mouse side buttons to bind actions in the game's key-binding settings.

- Supports back, forward, and other additional mouse buttons (buttons 4–7).
- Supports side-button combinations with Ctrl, Alt, and Shift.
- Supports editable bindings for game actions and mods such as CE that use the same settings panel.

</details>
