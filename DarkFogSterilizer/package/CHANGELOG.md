# Changelog / 更新日志

## 0.1.0

### 中文

- 支持清理指定星系的黑雾地面基地、太空巢穴、部队、中继站和相关在途火种。
- 按星系巢穴上限补满只有未完工中枢核心的绝育巢穴，核心有物质、零能量。
- 在星图底部中央提供“绝育星系”按钮，使用游戏原生弹窗确认目标星系和核心数量。

### English

- Clear a selected system's Dark Fog ground bases, space hives, units, relays and related tinders in transit.
- Fill the system's hive capacity with dormant hives, each containing only an unfinished core with matter and zero energy.
- Add a bottom-center starmap button with a native confirmation dialog showing the target system and final core count.
