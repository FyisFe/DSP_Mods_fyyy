# FullPhotonReceiver

射线接收站在光子和发电两种模式下，无视太阳朝向与戴森球供能限制，也不消耗戴森球能量。

功率按当前预热程度、透镜和增产剂计算，预热仍需逐步增加。光子模式按该功率生产临界光子；发电模式提供对应的发电容量，实际发电量由电网需求决定。

Ray receivers in both photon and power modes ignore sun direction and Dyson Sphere supply limits without consuming sphere energy.

Capacity follows the current warmup, lens and proliferator level; warmup still builds gradually. Photon mode produces critical photons at that capacity. Power mode provides the corresponding generating capacity, with actual generation determined by grid demand.
